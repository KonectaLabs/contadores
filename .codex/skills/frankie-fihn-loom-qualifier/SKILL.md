# Frankie Fihn Loom Qualifier

## Objetivo

Aclarar para quién funciona la oferta.

## Flujo

1. Definir buyer, situación y requisito mínimo.
2. Decir `esto funciona para vos si...` después de mostrar deseo.
3. Excluir casos que no pueden recibir valor.
4. Mantener pocos criterios relevantes.
5. No usar el qualifier como excusa para un target genérico.
6. Hacer que el formulario o respuesta capture sólo datos necesarios.
7. Conectar cada criterio con delivery real.

## Salida

- criterios;
- exclusiones;
- texto qualifier;
- preguntas;
- regla de avance.
