# Frankie Fihn Hand Raiser

## Objetivo

Conseguir una señal de interés antes de presentar toda la oferta.

## Flujo

1. Mostrar un outcome o problema reconocible.
2. Pedir una acción pequeña: comentar, responder, completar o pedir detalles.
3. Mantener el hand-raiser más corto que el Loom.
4. Filtrar compradores claramente no aptos cuando sea útil.
5. Evitar explicar todo el servicio.
6. Probar otro ángulo si nadie levanta la mano antes de abandonar el nicho.
7. Enviar el Loom sólo después de una señal válida o contexto suficiente.

## Salida

- hook;
- promesa;
- señal pedida;
- qualifier;
- respuesta siguiente.
