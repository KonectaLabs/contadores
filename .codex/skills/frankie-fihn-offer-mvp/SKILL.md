# Frankie Fihn Offer MVP

## Objetivo

Validar la secuencia comercial antes de construir infraestructura.

## Flujo

1. Definir un buyer estrecho.
2. Elegir un problema que ya quiera resolver.
3. Escribir una promesa concreta.
4. Crear el ejemplo mínimo que la vuelve visible.
5. Conseguir hand-raisers y conversaciones.
6. Confirmar capacidad de delivery manual.
7. Automatizar sólo después de señal suficiente.
8. Marcar este marco como `strong inference` cuando dependa del resumen secundario del catálogo.

## Salida

- buyer;
- problema;
- promesa;
- demo;
- test;
- gate de automatización.
