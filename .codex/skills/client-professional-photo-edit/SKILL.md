# Client Professional Photo Edit

Inspect the current portrait and the original reference photos when available.
Apply only the requested change. Preserve identity, age, facial proportions,
skin tone, hair and any approved styling that the request does not replace.

Do not progressively edit a low-quality derivative when the original reference
can produce a cleaner result. Do not invent a different person, office,
credential or business context.

For Website Agent:

1. save the new image as a separate candidate;
2. send it to the client for approval;
3. keep the previously approved image until the revision is approved;
4. place the approved result inside the page's `assets/` directory;
5. re-run desktop and mobile visual QA.

Never assume automation-specific paths, version tables, endpoints or jobs.
