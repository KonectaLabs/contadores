## Status Semantics

Use the `Status` column conservatively:

- `TODO`: no implementation has started.
- `Local`: implemented and tested on a local branch or local commit.
- `Main`: merged or committed to `main`.
- `Deployed`: deployed to the real server.
- `Server verified`: real-server smoke checks passed after deploy.

Individual plan executors should stop at `Local` unless the orchestrator explicitly starts the Contadores rollout sequence. Server verification belongs after commit, push, and deploy, not during isolated plan implementation.
