# Client Professional Photo

Use only client-provided photos as identity references. Inspect every source
before generating. Preserve face shape, age, skin tone, hair, distinguishing
features and overall recognizability.

Create a realistic professional portrait suitable for a landing page. Improve
lighting, crop, background and wardrobe only when requested or clearly useful.
Do not invent credentials, offices, teams, products or evidence.

For Website Agent, follow `website-agent/skills/image-workflow/SKILL.md`:

1. generate the portrait from the supplied source;
2. send the result to the client immediately;
3. ask for approval before adding it to the site;
4. store an approved image inside the page's own `assets/` directory;
5. verify the crop in desktop and mobile screenshots.

Never assume automation-specific folders, APIs, jobs or metadata contracts.
