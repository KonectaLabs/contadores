# Konecta Niche Marketing Memory

Facundo chose niches where Konecta's software, automation, documents,
websites, SEO and advertising capabilities can create leverage. Early markets
included real estate, lawyers and accountants.

The first implemented niche was accountants. The team researched pains,
desired outcomes and valuable services, then tested problem-first ad images.
The winning direction focused on accountants who depend on referrals and want
more recurring clients. Frankie Fihn material shaped the outcome-first offer,
short Loom structure and concrete buying step.

The reusable marketing process is:

1. research the niche and buyer language;
2. define a narrow outcome-led offer;
3. create two or three meaningfully different ad concepts;
4. test interest before building excessive infrastructure;
5. create a short deck and speaker script;
6. caption the recorded video;
7. preserve sources, approved assets and learnings for the next iteration.

Website Agent is now the only active Contadores product. This separate
marketing memory remains useful for research, acquisition and client work, but
it does not define product integrations or runtime behavior.

Useful current assets remain under `media/`, `abogados/`, the Frankie Fihn
skills and the external TikTok captions repository. Verify each path before
using it; do not infer a current runtime integration from historical notes.
