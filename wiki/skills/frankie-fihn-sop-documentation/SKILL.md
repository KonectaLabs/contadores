# Frankie Fihn SOP Documentation

## Objetivo

Reducir ambigüedad y dependencia personal.

## Flujo

1. Elegir un proceso repetido y estable.
2. Grabar una demostración corta cuando aporte contexto visual.
3. Escribir checklist ejecutable junto al video.
4. Definir input, output, owner y criterio de calidad.
5. Probar el SOP con otra persona.
6. Mejorarlo cuando aparezca una pregunta repetida.
7. No documentar caos como si fuera proceso definitivo.

## Salida

- objetivo;
- owner;
- Loom;
- checklist;
- QA;
- actualización.
